Static B-Trees

The Eytzinger layout turns binary search into a walk through an implicit tree. A static B-tree applies the same idea with wider nodes: fetch a block of sorted keys, determine one child number, and discard several binary decisions at once.

The word static matters. Without insertions or deletions, child positions can be derived from indices and nodes can be packed densely. A dynamic B-tree needs spare capacity, ownership, and explicit child references; that is the subject of the next chapter.

#From Binary to Wide Nodes

Let a node contain at most $B$ keys and therefore have $F=B+1$ child positions. Child $i$ contains values between parent keys $i-1$ and $i$, with either boundary omitted at an edge.

Number the root zero. In a complete $F$-ary Eytzinger layout, child $i$ of node $k$ is

$$ \operatorname{child}(k,i)=Fk+i+1, \qquad 0\le i\le B. $$ If there are $$ q=\left\lceil\frac{n}{B}\right\rceil $$ physical nodes, keep exactly the breadth-first prefix $[0,q)$. Its exact height is zero for $q=0$; otherwise it is one plus the number of times the last index $q-1$ can be replaced by its parent $\lfloor(k-1)/F\rfloor$ before reaching zero. Equivalently, it is the least $h$ such that $$ q\le 1+F+\cdots+F^{h-1}. $$

This definition handles a partial final layer without evaluating an overflowing power. The key capacity is $qB$, so fewer than $B$ slots are unused, but those slots are not necessarily all in the physically last node: in-order position and breadth-first position are different.

#An Implicit Static B-Tree

Construction performs an in-order traversal of the implicit tree and consumes the sorted input sequentially. Each node stores a count, so every 64-bit integer remains a legal key; no INT_MAX padding value is needed.

#include <algorithm>
#include <array>
#include <bit>
#include <cstddef>
#include <cstdint>
#include <limits>
#include <optional>
#include <span>
#include <stdexcept>
#include <utility>
#include <vector>

template <std::size_t Block = 16>
class static_b_tree_i64 {
    static_assert(Block >= 2);
    static_assert(
        Block < std::numeric_limits<std::size_t>::max()
    );

    struct node {
        std::array<std::int64_t, Block> keys{};
        std::size_t count = 0;
    };

public:
    explicit static_b_tree_i64(
        std::span<const std::int64_t> sorted_values
    ) : size_(sorted_values.size()) {
        if (!std::is_sorted(sorted_values.begin(), sorted_values.end()))
            throw std::invalid_argument("input must be sorted");

        const std::size_t count =
            size_ / Block + static_cast<std::size_t>(size_ % Block != 0);
        if (count > nodes_.max_size()
            || count > std::numeric_limits<std::size_t>::max() / Block)
            throw std::length_error("B-tree capacity overflow");

        nodes_.resize(count);
        std::size_t cursor = 0;
        if (!nodes_.empty())
            build(0, sorted_values, cursor);
        if (cursor != size_)
            throw std::logic_error("B-tree construction failed");
    }

    std::optional<std::int64_t>
    lower_bound(std::int64_t key) const {
        std::optional<std::int64_t> candidate;
        std::size_t index = 0;

        while (index < nodes_.size()) {
            const node& current = nodes_[index];
            const auto first = current.keys.begin();
            const auto last =
                first + static_cast<std::ptrdiff_t>(current.count);
            const auto found = std::lower_bound(first, last, key);
            const std::size_t slot = static_cast<std::size_t>(
                std::distance(first, found)
            );

            if (slot < current.count)
                candidate = current.keys[slot];

            const auto next = child_index(index, slot);
            if (!next)
                break;
            index = *next;
        }

        return candidate;
    }

    std::size_t size() const noexcept {
        return size_;
    }

    std::size_t height() const noexcept {
        if (nodes_.empty())
            return 0;

        constexpr std::size_t fanout = Block + 1;
        std::size_t index = nodes_.size() - 1;
        std::size_t result = 1;
        while (index != 0) {
            index = (index - 1) / fanout;
            ++result;
        }
        return result;
    }

private:
    std::optional<std::size_t>
    child_index(std::size_t parent, std::size_t slot) const noexcept {
        constexpr std::size_t fanout = Block + 1;
        if (slot > Block)
            return std::nullopt;

        const std::size_t offset = slot + 1;
        if (parent > (
                std::numeric_limits<std::size_t>::max() - offset
            ) / fanout)
            return std::nullopt;

        const std::size_t child = parent * fanout + offset;
        if (child >= nodes_.size())
            return std::nullopt;
        return child;
    }

    void build(std::size_t index,
               std::span<const std::int64_t> sorted_values,
               std::size_t& cursor) {
        node& current = nodes_[index];

        for (std::size_t slot = 0; slot < Block; ++slot) {
            if (const auto child = child_index(index, slot))
                build(*child, sorted_values, cursor);

            if (cursor < sorted_values.size()) {
                current.keys[current.count] = sorted_values[cursor];
                ++current.count;
                ++cursor;
            }
        }

        if (const auto child = child_index(index, Block))
            build(*child, sorted_values, cursor);
    }

    std::size_t size_;
    std::vector<node> nodes_;
};

At each node, the local lower bound selects a child. A local candidate is remembered before descending because the answer may be a separator in an ancestor rather than a key in the final node. An absent child ends the walk.

The child calculation checks multiplication and addition before forming the index. Real allocations will fail long before size_t is exhausted, but an arena bound is not a proof that intermediate arithmetic cannot wrap.

The build accepts duplicates. The search uses “first key not less than” at every level, so it retains lower_bound semantics. Returning a value is enough for a set-like index; an application that needs the original position or a payload can store that rank beside the key.

#B+ Layout and Fence Keys

A B+ tree separates navigation from data:

  • every record appears in a leaf;
  • internal nodes contain copies of boundary keys and child references;
  • all leaves have the same depth;
  • leaves are ordered, and they may be linked for range scans.

For a read-only array, the leaf records can remain contiguous and internal levels can form a separate index. The implementation below stores the maximum key of each child as its fence. Searching for x chooses the first child whose maximum is not less than x. This policy has two convenient properties:

  1. the final leaf is sufficient; lookup never has to repair an “all keys were smaller” result by reading its neighbor;
  2. duplicates that cross a leaf boundary still send lower_bound to the earliest child that can contain one.

If a level has $m$ children, it is partitioned into

$$ g=\left\lceil\frac{m}{B}\right\rceil $$

parents. Dividing the children as evenly as possible makes every non-root parent contain between $\lceil B/2\rceil$ and $B$ children. The same rule bulk-loads the leaves. This avoids a one-element tail node while retaining a completely uniform depth.

template <std::size_t Block = 16>
class static_bplus_index_i64 {
    static_assert(Block >= 2);

    struct index_node {
        std::array<std::int64_t, Block> maxima{};
        std::array<std::size_t, Block> children{};
        std::size_t count = 0;
    };

    struct descriptor {
        std::size_t index;
        std::int64_t maximum;
    };

public:
    explicit static_bplus_index_i64(
        std::span<const std::int64_t> sorted_values
    ) : values_(sorted_values.begin(), sorted_values.end()) {
        if (!std::is_sorted(values_.begin(), values_.end()))
            throw std::invalid_argument("input must be sorted");
        if (values_.empty())
            return;

        std::vector<descriptor> current = build_leaves();
        while (current.size() > 1) {
            const std::size_t group_count =
                ceil_div(current.size(), Block);
            const std::size_t small = current.size() / group_count;
            const std::size_t large_groups =
                current.size() % group_count;

            std::vector<index_node> level(group_count);
            std::vector<descriptor> next;
            next.reserve(group_count);

            std::size_t cursor = 0;
            for (std::size_t group = 0;
                 group < group_count;
                 ++group) {
                index_node& parent = level[group];
                parent.count =
                    small + static_cast<std::size_t>(
                        group < large_groups
                    );

                for (std::size_t slot = 0;
                     slot < parent.count;
                     ++slot) {
                    parent.maxima[slot] =
                        current[cursor].maximum;
                    parent.children[slot] =
                        current[cursor].index;
                    ++cursor;
                }

                next.push_back({
                    group,
                    parent.maxima[parent.count - 1]
                });
            }

            if (cursor != current.size())
                throw std::logic_error("level construction failed");

            levels_.push_back(std::move(level));
            current = std::move(next);
        }
    }

    std::size_t lower_bound_index(std::int64_t key) const {
        if (values_.empty())
            return 0;

        std::size_t leaf = 0;
        std::size_t node_index = 0;

        for (std::size_t level = levels_.size();
             level-- > 0;) {
            const index_node& current =
                levels_.at(level).at(node_index);
            const auto first = current.maxima.begin();
            const auto last =
                first + static_cast<std::ptrdiff_t>(current.count);
            const auto found = std::lower_bound(first, last, key);
            const std::size_t slot = static_cast<std::size_t>(
                std::distance(first, found)
            );

            if (slot == current.count)
                return values_.size();

            const std::size_t child = current.children[slot];
            if (level == 0)
                leaf = child;
            else
                node_index = child;
        }

        const std::size_t begin = leaf_begin_.at(leaf);
        const std::size_t end = leaf_end_.at(leaf);
        const auto first = values_.begin()
                         + static_cast<std::ptrdiff_t>(begin);
        const auto last = values_.begin()
                        + static_cast<std::ptrdiff_t>(end);
        return static_cast<std::size_t>(
            std::distance(values_.begin(),
                          std::lower_bound(first, last, key))
        );
    }

    std::optional<std::size_t>
    predecessor_index(std::int64_t key) const {
        const std::size_t position = lower_bound_index(key);
        if (position == 0)
            return std::nullopt;
        return position - 1;
    }

    std::size_t size() const noexcept {
        return values_.size();
    }

    std::size_t height() const noexcept {
        return values_.empty() ? 0 : levels_.size() + 1;
    }

private:
    static std::size_t ceil_div(std::size_t value,
                                std::size_t divisor) noexcept {
        return value / divisor
             + static_cast<std::size_t>(value % divisor != 0);
    }

    std::vector<descriptor> build_leaves() {
        const std::size_t leaf_count =
            ceil_div(values_.size(), Block);
        const std::size_t small = values_.size() / leaf_count;
        const std::size_t large_leaves =
            values_.size() % leaf_count;

        leaf_begin_.reserve(leaf_count);
        leaf_end_.reserve(leaf_count);
        std::vector<descriptor> result;
        result.reserve(leaf_count);

        std::size_t cursor = 0;
        for (std::size_t leaf = 0;
             leaf < leaf_count;
             ++leaf) {
            const std::size_t count =
                small + static_cast<std::size_t>(
                    leaf < large_leaves
                );
            const std::size_t begin = cursor;
            cursor += count;

            leaf_begin_.push_back(begin);
            leaf_end_.push_back(cursor);
            result.push_back({
                leaf,
                values_[cursor - 1]
            });
        }

        if (cursor != values_.size())
            throw std::logic_error("leaf construction failed");
        return result;
    }

    std::vector<std::int64_t> values_;
    std::vector<std::size_t> leaf_begin_;
    std::vector<std::size_t> leaf_end_;
    std::vector<std::vector<index_node>> levels_;
};

#if defined(__AVX2__)
#include <immintrin.h>

std::size_t avx2_lower_bound_16(
    const std::int32_t* initialized_keys,
    std::size_t count,
    std::int32_t key
) {
    if (count > 16)
        throw std::invalid_argument("node is wider than 16 keys");

    const __m256i query = _mm256_set1_epi32(key);
    const __m256i low = _mm256_loadu_si256(
        reinterpret_cast<const __m256i*>(initialized_keys)
    );
    const __m256i high = _mm256_loadu_si256(
        reinterpret_cast<const __m256i*>(initialized_keys + 8)
    );

    const unsigned low_mask = static_cast<unsigned>(
        _mm256_movemask_ps(_mm256_castsi256_ps(
            _mm256_cmpgt_epi32(query, low)
        ))
    );
    const unsigned high_mask = static_cast<unsigned>(
        _mm256_movemask_ps(_mm256_castsi256_ps(
            _mm256_cmpgt_epi32(query, high)
        ))
    );
    const unsigned valid =
        count == 16 ? 0xffffU : ((1U << count) - 1U);
    const unsigned less_mask =
        (low_mask | (high_mask << 8)) & valid;

    return static_cast<std::size_t>(std::popcount(less_mask));
}
#endif

For $n=0$, the index has height zero and lookup returns zero. Otherwise the leaf count is $\lceil n/B\rceil$, and each following count is obtained by applying $\lceil m/B\rceil$ until one root remains. That recurrence, rather than repeated floor division of $n$, is the exact height calculation for partial layers.

The reference stores child indices explicitly to make every partial-layer bound visible. A regular implicit layout can derive them and store only fence keys. Its key-only overhead approaches

$$ \frac{n}{B}+\frac{n}{B^2}+\cdots =\frac{n}{B-1}, $$

but real space also includes alignment, counts, ranks or payloads, and any child-index arena. A flat arena must check every node_count * node_width and accumulated level offset before allocating; using a signed int for those quantities is not sufficient.

#SIMD Local Search

Within one node, the local lower bound is the number of valid keys less than the query. For 16 sorted 32-bit keys, AVX2 can compare two vectors, extract two eight-bit masks, and apply population count; related mask-compaction techniques are covered with SIMD shuffles. The optional routine above does exactly that when compiled for AVX2.

Three details are correctness requirements:

  • it loads 16 initialized objects even when count < 16, then masks out invalid lanes;
  • it uses unaligned loads, so callers do not acquire a hidden 32-byte alignment precondition;
  • it counts key > node_key, which implements strict “less than” and therefore handles duplicates and INT32_MAX without subtracting one from the query.

Packing vector masks can permute lanes. If that alternative is used, a rank-to-slot lookup needs an entry for every real rank and a separate $B$ outcome meaning “no local candidate.” Test rank < count before dereferencing the table; mapping the $B$ outcome back to slot zero changes the answer. Population count avoids the lookup entirely because only the number of true lanes matters.

AVX2 is not a portable C++ feature. Other targets need a scalar fallback or implementations using their own intrinsics, mask operations, and vector widths. Node width should be chosen together with cache-line size, alignment, comparison cost, and fanout—not copied from one historical benchmark.

#Keys, Duplicates, and Predecessors

These examples use signed integers and no sentinel, so the complete type domain is accepted. With floating-point keys, ordinary comparisons do not impose a useful total order on NaNs. A constructor must either reject NaNs or use one documented total-order comparator consistently for sorting, fence construction, and lookup.

lower_bound(x) returns the first key $y$ for which $y<x$ is false. The strict predecessor is the element immediately before that position; it excludes keys equal to $x$. A predecessor that permits equality instead starts from upper_bound(x). Calling both operations “predecessor search” without specifying strictness produces boundary bugs around duplicates.

#What the Layout Buys

Wider nodes reduce the number of dependent fetches from $\Theta(\log_2 n)$ to $\Theta(\log_B n)$, but local work and transferred bytes increase with $B$. SIMD can make that local work cheap, while independent searches may overlap through memory-level parallelism. Neither effect is universal.

A useful benchmark separates preprocessing, independent-query throughput, and dependency-chained latency. It includes empty and partial layers, duplicates, absent keys, extreme values, and sizes around cache and TLB boundaries. It also records compiler target flags: executing an AVX2 build on a processor without AVX2 is not a slow path but an invalid binary.

# Algorithmica β

This repository contains the static GitHub Pages build of Part I, Performance Engineering, from Algorithmica.

Only the HPC book and the assets it references are published on the `main` branch. The exact editable source used for this build is kept on the [`source` branch](https://github.com/anpaure/algorithmica-beta/tree/source); it is based on the upstream [Algorithmica repository](https://github.com/algorithmica-org/algorithmica).

The bundled Algorithmica theme is MIT-licensed; see `THEME-LICENSE`. Book content remains attributed to Sergey Slotin, as shown on every published page.
